Here's a cheat sheet for different VS Code shortcuts I've collected over time (on a Mac though).

## Interact with code

<!-- prettier-ignore-start -->
|Shortcut|Description|
|---|---|
|`Cmd+K+C`| Comment out a line. |
|`Cmd+K+U`| Uncomment a line-comment. |
|`Cmd+C`| Copy selection to clipboard. |
|`Cmd+V`| Paste selection in clipboard. |
|`Cmd+X`| Cut out selection and copy it to clipboard. |
|`Cmd+Z`| Undo something. |
|`Cmd+Shift+Z`| Undo what you just undid. |
|`Option+Z`| Activate line wrapping for a file where lines overflow. |
|`Option+Up/Down Arrow`| Move code lines around. |
|`Option+Right/Left Arrow`| Move cursor between words. |
|`Ctrl+Up/Down Arrow`| Scroll up/down |
| `Ctrl+D` | If the cursor is on a specific word it will look for the recurring word in the file and select it as well. |


## Interact with Code Editor
|Shortcut|Description|
|---|---|
|`Cmd+P`| Open search field. |
|`Cmd+Shift+P`| Open search field for command prompts. |
|`Cmd+J`| Toggle panel. |
|`Cmd+B`| Toggle primary sidebar. |
|`Cmd+Shift+B`| Toggle secondary sidebar. |

## Advanced
|Shortcut|Description|
|---|---|
|`Cmd+Shift+P`| Open command prompt. |
|`Cmd+Shift+7`| Open preview of markdown files. |

## Inside CLI
|Shortcut|Description|
|---|---|
|`Ctrl+A`| Move cursor to beginning of line. |
|`Ctrl+E`| Move cursor to end of line. |
